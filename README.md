# Jay Labatorio Portfolio

A modern, responsive personal portfolio for Jay Labatorio, presenting his work as a Virtual Assistant, IT Support Specialist, data professional, and Graphic Designer. The site is designed as a premium single-page experience for remote clients, with clear service positioning, representative project work, professional strengths, and a direct inquiry flow.

## Key Technologies

- TanStack Start and TanStack Router
- React 19 and TypeScript
- Tailwind CSS 4 with a custom design system
- Lucide React icons
- Netlify Forms for contact inquiries
- Netlify deployment adapter for TanStack Start

## Features

- Responsive single-page portfolio with sticky navigation
- Light and dark themes with saved preference
- Filterable project gallery
- Animated hero, skill bars, and interactive cards
- Mobile navigation and scroll-to-top control
- Accessible form labels, focus states, reduced-motion support, and skip navigation
- SEO metadata and downloadable text resume
- Netlify Forms integration with honeypot spam protection

## Local Development

Install dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

For full Netlify platform emulation, use:

```bash
netlify dev --port 8889
```

## Content Notes

The email address and external social profile links are placeholders because verified contact details were not provided. Replace them in `src/routes/index.tsx` and `public/jay-labatorio-resume.txt` before publishing the site publicly. The testimonials are explicitly labeled as sample content.
